# Цветочный бот

Личный Telegram-бот про комнатные растения.

- Присылаешь фото цветка, бот коротко отвечает: что это, всё ли с ним ок, норм ли горшок, как часто поливать и что сделать прямо сейчас.
- Утром (с 9:00 по Москве) пишет, кого пора полить. Вечером (с 19:00) напоминает, если кто-то остался.
- В чате есть кнопка «Мои цветы». Она открывает приложение со списком цветов, отметками полива и сканером.

Бот личный: кто первым нажал «Начать», тот и хозяйка. Остальным он отвечает, что занят.

## Из чего состоит

| Что | Где |
| --- | --- |
| Сервер бота и приложения (Node.js 22) | хостинг [Amvera](https://amvera.ru) |
| База: цветы, поливы, служебные значения | [Supabase](https://supabase.com), таблицы `plants`, `waterings`, `kv` |
| Фото цветов | Supabase Storage, бакет `photos` |
| Сканер: одна модель смотрит на фото, вторая пишет вывод и советы | [OpenRouter](https://openrouter.ai) |
| Специализированная модель по растениям (вид и болезни), подсказка сканеру | [Plant.id](https://www.kindwise.com/plant-id), необязательно |

```
src/
  index.js      веб-сервер: вебхук Telegram, API приложения, часы для напоминалок
  bot.js        что бот делает в чате
  scan.js       запрос к модели и разбор ответа
  db.js         работа с Supabase
  telegram.js   запросы к Telegram, проверка, что приложение открыла хозяйка
  config.js     настройки из переменных окружения
  dates.js      даты по московскому времени
public/         приложение (Telegram Mini App)
supabase/schema.sql   таблицы, бакет и стартовый список цветов
amvera.yml      как Amvera собирает и запускает бота
```

## Запуск

### 1. Бот в Telegram

В [@BotFather](https://t.me/BotFather): `/newbot`, придумать имя, сохранить токен.

### 2. Supabase

1. Создать проект на supabase.com (регион любой, лучше Европа).
2. **SQL Editor → New query**, вставить весь `supabase/schema.sql`, нажать **Run**. Появятся таблицы, бакет для фото и 11 цветов.
3. **Project Settings → API**: скопировать **Project URL** и ключ **service_role** (секретный, никому не показывать).

### 3. Amvera

1. Создать проект типа «Приложение», загрузить этот код (через Git или архивом). `amvera.yml` уже лежит в корне.
2. **Настройки → Домены**: подключить бесплатный домен вида `имя-проекта.пользователь.регион.amvera.tech`.
3. **Переменные** (все секретные):

| Переменная | Что туда |
| --- | --- |
| `BOT_TOKEN` | токен от BotFather |
| `PUBLIC_URL` | домен из шага 2, с `https://` |
| `SUPABASE_URL` | Project URL из Supabase |
| `SUPABASE_SERVICE_KEY` | ключ service_role |
| `LLM_API_KEY` | ключ OpenRouter (необязательно: без него не работает только сканер) |

Необязательные: `LLM_VISION_MODEL` — модель, которая смотрит на фото (по умолчанию `deepseek/deepseek-v4-flash-vision-exp`); `LLM_TEXT_MODEL` — модель, которая по описанию фото пишет вывод и советы (по умолчанию `~deepseek/deepseek-v4-flash-latest`, пустое значение — всё делает модель для фото); `LLM_BASE_URL` (по умолчанию `https://openrouter.ai/api/v1`, подойдёт любой OpenAI-совместимый адрес); `PLANT_ID_API_KEY` — ключ Plant.id: с ним сканер сначала спрашивает специализированную модель по растениям и сверяет с ней вид и болезни; `PORT` (по умолчанию 80).

4. Перезапустить проект. При старте бот сам подключает вебхук и кнопку «Мои цветы». В логах должно появиться «Telegram подключён».
5. Написать боту `/start`.

## Настройки в коде

В `src/config.js`: часовой пояс (`TZ_OFFSET_HOURS = 3`), час утренней и вечерней напоминалки, можно выключить вечернюю (`EVENING_NUDGE = false`).

## Проверка у себя

```
npm install
BOT_TOKEN=... PUBLIC_URL=... SUPABASE_URL=... SUPABASE_SERVICE_KEY=... LLM_API_KEY=... PORT=3000 npm start
```

Telegram ходит только на `https`, поэтому для настоящего вебхука нужен публичный адрес.
